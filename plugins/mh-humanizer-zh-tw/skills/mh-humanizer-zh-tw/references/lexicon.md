# 詞彙表：兩岸用語對照與 AI 高頻警示詞（台灣正體版）

## 目錄

- **一、大陸用語 → 台灣用語對照**：AI／軟體與操作語境｜軟體開發領域補充（IT／AI／DevOps／資安／雲端／Data）｜產品術語縮寫習慣差異｜實務慣用優先原則｜編輯寫作與商務語境｜不可機械替換清單
- **二、台灣繁中 AI 高頻警示詞（四類）**：模板詞｜公關腔風險｜英文翻譯腔｜陸式用語滲入｜自上游降級調整的詞
- **三、台灣特有贅詞句型**

## 使用原則

- **對照表用於偵測與轉換大陸用語**，但一律先過「不可機械替換清單」——同形異義詞必須依語境判斷。
- **警示詞表不是禁用詞表。** 單字命中不足以判定 AI 痕跡；應檢查頻率、密度、句型與上下文。真人公文、學術與公關稿也會使用這些詞。
- 正確寫法示例：不是「發現『此外』就刪除」，而是「若『此外、同時、然而、因此』在短篇中反覆擔任段首連接詞，檢查段落間是否真有遞進、轉折或因果關係；沒有就刪除連接詞或合併內容」。
- 豁免清單（程式碼、UI 字串、引用原文等，見上層 SKILL.md）內的文字一律不改。
- 對照表以英文原詞為錨點——不確定該用哪個台灣譯名時，回到英文原詞判斷語境；行文用縮寫前，首次出現建議寫「全名（縮寫）」。

### 實務慣用優先原則（官方譯名 vs 實際用語）

**判準是「台灣工程師與讀者實際怎麼說」，不是官方對照表。** 把通用詞矯正成無人使用的官方譯名，會讓文字更不自然——這本身就是一種在地化失敗。

**陸源（或兩岸同形）但台灣已通用——勿矯正：**

| 通用詞 | 官方／教科書譯名 | 英文全名 | 縮寫 | 說明 |
|---|---|---|---|---|
| 大數據 | 巨量資料、海量資料 | Big Data | | 官方譯名幾乎無人使用，保留「大數據」 |
| 優化 | 最佳化 | Optimize | | 台灣技術寫作「效能優化」已通用；僅一般語境可改「改善」 |
| 網紅 | — | Influencer | | 陸源詞，台灣已完全通用 |
| 痛點 | — | Pain Point | | 商業語境已通用；一般寫作仍可改「問題、困難」 |
| CP 值 | 性價比 | Cost-Performance Ratio | CP | 台灣口語慣用 CP 值 |

**無慣用中譯——直接保留英文：**

metadata（官方譯「詮釋資料」「中繼資料」，實務直接寫 metadata）、token、schema、payload、callback、hook、webhook、race condition、deadlock（「死結」教科書用，實務常直寫）、legacy code、code review、bug／debug（口語；正式文件可用「除錯」）

保留英文時維持原大小寫，中英文之間留半形空格。此原則與 T4（中英夾雜偽專業感）互補：**必要術語保留英文是自然，普通概念包裝成英文才是問題。**

### 不可機械替換清單（必依語境判斷）

- **質量**：物理量不能改成品質
- **程序**：法律程序、行政程序不能改成程式
- **文件**：法律文件、政策文件不能改成檔案
- **資訊／資料／數據**：三者在台灣不是同義詞
- **支持／支援**：支持主張，支援功能
- **透過／通過**：透過方法，通過審查
- **最佳化／改善**：有明確目標函數才用最佳化
- **對象**：程式的 object 是物件；論述、交往的對象仍是對象
- **Agent**：Claude Code 等產品概念可保留英文；一般說明用「AI 代理」

## 二、台灣繁中 AI 高頻警示詞（四類）

四類是**不同維度**的警示（模板／公關腔／翻譯腔／陸式詞），不是嚴重程度排序。各類檢查方式不同，見各類說明。

### 第 1 類：模板詞——台灣 AI 文常見固定模板

**檢查方式：密集才查**——單字不是問題，短文中密集重複才是。

**段首連接詞（只做段首密度檢查，本身是正常篇章成分）：** 此外、同時、然而、因此、換句話說、總體而言、整體而言

**模板詞：** 值得注意的是、值得一提的是、不容忽視、不難發現、可以看出、由此可見、綜上所述、總而言之、在此背景下

**模板句型：** 隨著……不斷……、在……的浪潮下、在當今快速變化的……、面對日益複雜的……、無論是……還是……、不僅……更……、不只是……更是……、透過……來……、藉由……進一步……、涵蓋……等多個面向、扮演重要角色、發揮關鍵作用、帶來深遠影響、開啟新的可能性、邁向新的里程碑、為未來奠定基礎、注入新的活力、成為不可或缺的一環、讓我們一起……、接下來，我們將……、以下將從三個面向……、本文將帶您了解……、相信透過……、期待未來……、未來可期

### 第 2 類：公關腔風險——台灣企業／政府／公關稿常見

**檢查方式：密集出現或無具體對象才查，依文類豁免**（公關稿文類本身可保留部分）。真人公關稿也常用，標記為「公關腔風險」而非 AI 判定：

### 第 3 類：英文翻譯腔——英文模型直譯痕跡

**檢查方式：單次即查**（這些搭配在自然台灣中文裡罕見）。

### 從上游（大陸版）詞表降級／調整的詞

- **格局**：台灣會用，僅「重塑格局／全新格局」值得警示
- **彰顯**：政府、公關、學術文章確實在用，不移除但檢查密度與是否有具體對象
- **織錦**：非台灣高頻詞，列為英文 tapestry 直譯警示
- **領域、重要、關鍵、全面、有效**：太普通，只偵測密度與空泛搭配，不單獨警示
- **革命性、顛覆性**：非日常高頻，但在 AI 產品介紹中仍是強宣傳警示

## 三、台灣特有贅詞句型

- **「在……的部分」**取代直接主詞：「在操作介面的部分」→「操作介面」；「費用的部分」→「費用」
- **「進行＋名詞」**：進行了解、進行改善、進行討論 → 直接用動詞
- **「相關」空泛化**：「相關資訊」「相關規定」「相關作業」卻未指出是哪些 → 寫明具體內容
- **「包含但不限於」**製造假完整性 → 直接列出，或說明取樣原則
- **段落結尾口號**：每段落在「提升整體體驗」「創造更大價值」→ 刪除或改具體成果
